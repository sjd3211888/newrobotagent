## 建立每轮对照

原工程来源位于本机 `D:\voiceagent`。关键阅读来源包括 `README.md`、`docs/development/architecture-current-2026-09-20.md`、近期 `docs/superpowers/specs/` 及对应工作区源码。原工程包含未提交修改，文档部分描述落后于实现；运行部署需另行核对。

每轮在本目录建立对应功能需求，按[需求模板](../templates/requirement.md)写具体旧行为、来源、输入样本、成功和失败条件，并关联设计与报告。状态依次记录“未迁移”“开发中”“本地验证通过”“实机验收通过”；不适用实机的纯软件功能明确说明理由。最终对照表必须细化到可验收行为，不能仅用上表能力组宣称全功能等价。

## 新平台目标

模型替换、分离式 ASR/LLM/TTS 与实时多模态、网页任务入口、通用 MCP/HTTP 工具、多客户/设备隔离属于新平台目标。它们与旧功能保留分开验收，详见[选型研究](../research/robot-agent-eino-selection-2026-10-09.md)。

本轮只验收工程规范；业务验收方案从后续场景迭代开始建立。
