# 工程规范导航

状态：有效 · 日期：2026-10-10 · 范围：全仓库 · 关联：ITER-001

按以下顺序阅读和执行。本文是导航；每项详细规则只在对应文件维护。

1. [目录与模块边界](layout.md)：代码、协议、配置、测试和产物的放置。
2. [编码规范](coding.md)：职责、接口、错误、并发、模型与物理执行。
3. [文档规范](documentation.md)：有效说明、历史记录、编号、链接和模板。
4. [迭代规范](workflow.md)：从场景需求到本地交付的完整流程。
5. [测试与验收规范](testing.md)：测试层级、自动检查和证据要求。
6. [Git 与交付规范](git-delivery.md)：分支、提交、依赖、配置、发布与回滚。

基础规则通过[检查脚本](../../scripts/check.py)执行，设计质量和业务正确性通过评审、场景验收确认。规则新增或修改需解释原因、影响范围，并同步检查脚本或人工评审清单。

本轮规范的决策依据见 [ADR-001](../decisions/ADR-001-engineering-governance.md)。
